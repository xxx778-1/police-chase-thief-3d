# 警察抓小偷 3D（Police Chase Thief 3D）

一款基于 Three.js + Socket.io 的 3D 直播弹幕互动实时对战游戏。观众可以选择加入警察或小偷阵营，在 3D 城市地图中展开追逐与躲藏，使用道具攻防，最终达成阵营胜利。

## 游戏特色

- **3D 城市场景**：精美的夜景城市，包含道路、建筑、灯光与边界围墙
- **阵营对抗**：警察 vs 小偷，实时显示双方人数与积分
- **道具系统**：双方各 3 种特色道具
  - 警察：手铐、警犬、路障
  - 小偷：烟雾弹、疾跑、伪装
- **实时对战**：支持多人在线，WASD 移动，鼠标旋转视角
- **直播弹幕**：内置弹幕互动面板，模拟直播氛围
- **离线模式**：无服务器时自动进入本地 AI 演示模式

## 快速开始

### 方式一：Windows 一键启动（推荐）

双击运行 `start.bat`，脚本会自动检测 Node.js 并启动游戏。

- 如果已安装 Node.js：启动服务器，自动打开浏览器访问 `http://localhost:3000`
- 如果未安装 Node.js：直接用浏览器打开离线演示模式

### 方式二：命令行启动

```bash
# 安装依赖
npm install

# 启动服务器
npm start

# 浏览器访问
http://localhost:3000
```

## 操作说明

| 按键 | 功能 |
|------|------|
| W / A / S / D 或方向键 | 移动角色 |
| 鼠标拖动 | 旋转视角 |
| 鼠标滚轮 | 调整视距 |
| 1 / 2 / 3 | 使用对应道具 |

## 游戏规则

1. 玩家通过界面按钮选择加入警察或小偷阵营
2. 警察需要靠近小偷进行抓捕
3. 小偷需要躲避警察直到倒计时结束
4. 警察抓完所有小偷则警察胜利
5. 倒计时结束时仍有小偷存活则小偷胜利
6. 合理使用道具可以改变战局

## 技术栈

- 前端：HTML5 + CSS3 + JavaScript + Three.js
- 后端：Node.js + Express + Socket.io
- 平台：Windows / macOS / Linux（浏览器即可运行）
